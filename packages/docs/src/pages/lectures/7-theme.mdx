## Real, typed variables

`property()` registers a CSS [`@property`](https://developer.mozilla.org/en-US/docs/Web/CSS/@property) and gives you back a token you can drop in as a value. It compiles to `var(--name)`.

```ts
const primary = property('primary', '#3498db', '<color>');

select('.btn').style({ background: primary });
// -> .btn { background: var(--primary); }
```

The third argument is the [syntax](https://developer.mozilla.org/en-US/docs/Web/CSS/@property/syntax), so the browser knows the type (and can even animate it).

## Tokens and themes

For a whole set of variables, use `surimi/theme`. `defineTokens` declares your tokens with their default values, which are set on `:root`:

```ts
import { createTheme, defineTokens, token } from 'surimi/theme';

const tokens = defineTokens({
  background: token('#fff', '<color>'),
  text: '#111',
});
```

Every key is a token, and `tokens.background` compiles to `var(--background)`. Wrapping a value in `token()` also registers it as a typed `@property`.

A theme is a set of new values for some of those tokens. `createTheme` returns a style, so you decide where it applies with `.use()`:

```ts
const dark = createTheme(tokens, { background: '#111', text: '#eee' });

select('[data-theme="dark"]').use(dark);
```

Change a value in the example above and the button follows. The **Toggle dark mode** button sets `data-theme` on the document root, so you can see the dark theme take over live.

Follow the OS setting too: `media().prefersColorScheme('dark').select(':root').use(dark)`. Writeup: [Theming](/docs/guides/theme).

## The superpower: it's just TypeScript

Export tokens and themes from their own file and import them anywhere, fully typed:

```ts
// theme.css.ts
export const tokens = defineTokens({ ... });
export const dark = createTheme(tokens, { ... });
```

(In this single-file playground we keep them inline, but in a real project each `.css.ts` emits its own CSS and shares the tokens through normal imports.)
